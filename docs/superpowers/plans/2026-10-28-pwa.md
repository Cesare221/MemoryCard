# PWA Implementation Plan

**Goal:** Instalar Memory Depo no celular com fallback offline explícito.
**Architecture:** Manifest e worker estáticos, componente React de instalação compartilhado entre login e cabeçalho.
**Tech Stack:** React, Vite, Vitest, APIs PWA nativas.
**Spec:** ../specs/2026-10-28-pwa-design.md

## Constraints
- Sem cache de autenticação ou respostas do Supabase.
- Sem edição offline completa neste escopo.
- Preservar alteração existente de vite.config.js.

## Tasks
- [x] Criar manifest, ícones PNG, página offline e worker; registrar somente em produção.
- [x] Criar InstallApp com prompt nativo, instruções alternativas e detecção de standalone; integrar no login e cabeçalho.
- [x] Testar prompt aceito/cancelado/falho, modo instalado e cache limitado ao fallback; executar suíte e build.
- [x] Preservar configuração Supabase original confirmada pelo usuário; documentar diagnóstico, publicação e recomendações de design.

## Review focus
Evento antes do clique, cancelamento sem falsa confirmação, Safari sem beforeinstallprompt, atualização do worker sem apagar caches alheios, navegação com tokens sem persistência em cache.
